# Walkable Pocket Garden

Run: npm install, then npm run dev. Build: npm run build. Publish dist/ to a static host.

WASD/arrows to move, drag to turn camera, E or action button to interact. Touch uses the thumbstick. Map buttons visit landmarks directly. Return arrow resets location. Sound starts on entering; toggle to mute. Four landmarks preserve the original messages and anonymous final note.

The user approved replacing the illustrated parallax approach with actual 3D. This is a stylized original Three.js scene with volumetric trees, instanced blossoms and flowers, a stone path, lanterns, pond, mountains, falling petals, following camera and obstacle avoidance. It does not reproduce Bruno Simon's assets or code.

References: https://www.bruno-simon.com/ for exploration, landmarks, map and reset; https://www.awwwards.com/sites/ponpon-mania for playful narrative responses; https://threejs.org/docs/ for implementation.

Limitations: not equivalent to Bruno Simon's extensive production; no custom modeled characters or physics engine. Procedural blossoms look stylized rather than anime-realistic. Physical phone performance and audio listening require device testing. Map travel is instantaneous. Reduced motion disables petals and camera smoothing.
